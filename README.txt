⚽ Football Analytics Pro - Установка (Windows)

📦 Что внутри:
  • football_analytics_bot.zip — архив проекта
  • Установить_Проект.bat — автоматическая установка (двойной клик)
  • setup.py — альтернативная установка через Python

🚀 Установка:

Способ 1 (проще): Дважды кликните на Установить_Проект.bat
Способ 2: Откройте консоль и введите: python setup.py

🎯 После установки появятся ярлыки:
  • Запустить_Дашборд.bat
  • Анализ_Матчей.bat
  • Telegram_Бот.bat
  • Обновить_Данные.bat

⚠️ Требования: Python 3.10+, Windows 10/11
